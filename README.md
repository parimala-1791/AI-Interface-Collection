# 🤖 NexoraAI

## AI Interface Collection

NexoraAI is a collaborative college project that brings together multiple
modern and interactive AI-inspired web interfaces in one platform.

The project is developed using HTML, CSS and JavaScript. Each interface
focuses on a different AI-based concept and provides a simple,
user-friendly experience.

---

## ✨ Features

- 💬 AI Chat
- 🔍 AI Search
- ✨ AI Prompt
- 🤖 AI Recommendation
- 🎨 AI Image Generator
- 📄 AI Document Summarizer
- 💻 AI Code Assistant
- 🌐 AI Translator
- 🍱 AI Food Planner
- 🛍️ AI Shopping Assistant
- 💡 AI Idea Generator
- 🧠 AI Interface Collection
